Body Example Docs

Core Class

  • animation/components/body.mjs exports AnimationBody.
  • Combines position, velocity, rotation, anchor, and scale into CSS-variable-based rendering.

Primary Methods

  • setAnchor(value): parse and apply anchor ratios.
  • moveTo(x, y): set body position directly.
  • freezeAt(x, y, z): set frozen position for tracking modes.
  • viewerPosition(), getStagePosition(), relativePosition(el).

Important Properties

  • position, velocity, rotation, scale.
  • width, height, anchor, debug.
  • worldPosition: synchronized with runtime movement for camera/follow logic.

Technical Notes

  • Update step mutates state; render step writes batched style variables.
  • Viewport visibility checks avoid unnecessary render writes when off-screen.
  • Debug mode updates runtime stat labels on the anchor marker.
