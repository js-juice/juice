Easing Example Docs

Purpose

  • Visual reference for all easing functions in animation/easing.mjs.
  • Each row shows curve shape and current eased output at the same timeline phase.

Easing Source

  • Imported default object from animation/easing.mjs.
  • Includes linear, quad/cubic/quart/quint, sine, expo, circ, back, elastic, and bounce families.

Runtime Flow

  • animation-stage provides the local timeline.
  • timeline-controls controls playback speed, direction, stepping, and reset.
  • Animator samples each easing at t = timelinePhase and updates all rows.
