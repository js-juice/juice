Stage Example Docs

Class Type

AnimationStage Animation Component

This is a core component class for rendering and animating stage content. It can be used in standalone mode with its own timeline or as a child of AnimationViewer, where it integrates with the viewer's timeline and camera system.

import'animation/components/stage.mjs';

Class Overview

  • animation/components/stage.mjs exports AnimationStage.
  • Standalone mode: uses local timeline.
  • Viewer mode: timeline ownership moves to viewer.timeline.

Primary Methods

  • addAnimator(animator): attach update/render targets to stage or viewer timeline.
  • addBackground(element, options): append to world or parallax.
  • moveTo(x, y): absolute stage position.
  • move(dx, dy): incremental stage movement.
  • setAnchor(anchor): resolves anchor string to pixel anchor point.

Attributes and Runtime Properties

  • Attributes: width, height, x, y, fps, anchor, debug.
  • Runtime: position, anchorPoint, bounds, viewer, timeline, animatorChildren.

Technical Notes

  • Host element is positioned as a point; stage scene content is shifted by anchor CSS vars.
  • Bounds are synchronized with anchor and viewer dimensions.
  • Camera bounds are derived from stage bounds in viewer mode.
