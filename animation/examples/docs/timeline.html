Timeline Example Docs

Core Class

  • animation/timeline.mjs exports Timeline.
  • Execution is managed by an internal shared ticker.

Primary Methods

  • play(), pause(), reset().
  • setReverse(boolean), setTimeScale(number).
  • addAnimator(animator), addUpdate(fn), addRender(fn).
  • afterUpdate(fn, options) for post-update hooks.

Time Object Fields

  • time.ms: elapsed milliseconds.
  • time.delta: seconds since previous processed step.
  • time.fps: instantaneous processed-step FPS value.
  • time.frame: processed frame counter.

Technical Notes

  • FPS cap uses an accumulator so sub-frame jitter does not force 30/60 oscillation.
  • Update and render callbacks run only when timeline has active work.
  • Time scale supports both forward and reverse playback.
