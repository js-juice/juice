Sprite Base Example Docs

Core Class

  • animation/components/sprite.mjs exports AnimationSprite.
  • Handles sprite sheet loading and frame-window rendering through SpriteSheet.

Primary Methods

  • next(), prev(): frame stepping helpers.
  • addSheet(src, width, height): append a sprite source.
  • update(time): auto-play frame advancement by tempo.
  • render(force): commit sprite sheet view updates.

Main Attributes

  • src, width, height, frames, frame.
  • tempo, in, out, loop, auto.

Technical Notes

  • Frame changes synchronize to the underlying sprite sheet frame index.
  • Auto mode advances by elapsed timeline delta and configured tempo.
  • Render path avoids redundant work unless sprite state is dirty or forced.
