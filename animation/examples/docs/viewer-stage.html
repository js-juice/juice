Viewer + Stage Example Docs

Class Stack

  • AnimationViewer: timeline owner and camera host.
  • AnimationStage: world space, anchor, bounds, transform target.
  • Camera: follow target and bound clamping.
  • AnimationBodyTarget: plain DOM animator wrapper for probe motion.
  • AnimationMinimap: preview overlay with stage/view/dot projection.

Primary Methods

  • viewer.follow(target): camera tracks target position.
  • stage.addAnimator(animator): animator registration with stage/viewer timeline.
  • body.setPosition(x, y), body.setVelocity(x, y), body.setUpdate(fn).
  • camera.update(time): reads target and clamps camera to min/max.

Technical Behavior

  • Viewer centers stage host; stage anchor offset is applied inside stage scene root.
  • Camera position is translated into stage transform using viewer center + stage anchor.
  • Stage bounds lock camera-following motion to scene limits.
  • Minimap scales world coordinates into a fixed-size overlay map.
