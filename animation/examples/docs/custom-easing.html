Custom Easing Example Docs

Purpose

  • Create a custom easing curve by adding and dragging control points.
  • Compare linear output vs custom output at the same timeline phase.

Interaction Model

  • Fixed endpoints: (0,0) and (1,1).
  • Click the blue curve to add new intermediate points.
  • Each point has a tangent handle for local smoothing control.
  • Curve output uses piecewise cubic interpolation across all points.

Runtime Flow

  • animation-stage timeline provides time progression.
  • timeline-controls handles play/pause/step/reset/speed/reverse.
  • Panel provides a copyable CSS easing function string.
