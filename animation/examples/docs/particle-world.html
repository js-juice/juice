Particle World Example Docs

Core Component

  • animation/components/particle-world.mjs defines the particle-world custom element.
  • Supports renderer modes including webgl and canvas.

Runtime Focus

  • This example uses renderer="webgl" for GPU-driven particles.
  • Orbit and repel flags are toggled through footer buttons.
  • Target position/radius are updated through random target control.

Useful Runtime Methods

  • world.particleViewer.setValue(name, value) updates particle uniforms/options.
  • Common names used here: orbit, repel, orbitPoint[i], repelPoint[i].
