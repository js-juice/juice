Sprite Extended Example Docs

Class Stack

  • animation/examples/rocket-sprite.mjs exports RocketSprite.
  • RocketSprite extends AnimationSprite.
  • Uses SpriteSheet with custom yaw-driven frame mapping.

Primary Methods

  • setFrameByDegree(degree): maps yaw degrees to sprite frame index.
  • addDegrees(delta): increments yaw and updates frame.
  • onFirstConnect(): sets dimensions, sheet, styles, and loads texture.

Technical Notes

  • Yaw cycles through a 120-degree window and converts to 29-frame index range.
  • A layered porthole overlay is synchronized with CSS --yaw.
  • Sprite sheet load dispatches sheet-ready once initial frame is rendered.
