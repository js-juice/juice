# Sprite Base

Base `animation-sprite` usage with direct frame playback.

## Uses
- `animation/components/sprite.mjs`
- sprite sheet: `animation/examples/assets/rocket-yaw-sheet-med.png`

## Element Attributes
- `src`: sprite sheet URL
- `width`: sprite viewport width
- `height`: sprite viewport height
- `frames`: number of frames in the sheet
- `frame`: current frame index
- `auto`: auto-play (not used in this demo)
- `loop`: loop playback (not used in this demo)
