# Timeline

Timeline demo driven by an `animation-stage` local timeline and controlled by `timeline-controls`.

## Uses
- `animation/components/stage.mjs`
- `animation/components/timeline-controls.mjs`

## Features Demonstrated
- Timeline playback control via footer `timeline-controls`
- Live timeline readout (cycle/fps/frame/state)
- Reverse playback and speed scaling through controls

## Time Fields Used
- `time.ms`
- `time.fps`
- `time.frame`
