# Particle World

`particle-world` example using the WebGL renderer.

## Uses
- `animation/components/particle-world.mjs`

## What This Example Shows
- GPU particle rendering via `renderer="webgl"`
- Orbit/repel mode toggles
- Randomized target point updates

## Controls
- `Orbit`: enables/disables orbit behavior.
- `Repel`: enables/disables repel behavior.
- `Random Target`: picks a new target position/radius.
