Emitter example

This example demonstrates `animation/particles/emitter.mjs`.

Controls:
- `Particles / sec` — emission rate
- `Speed` — emitted particle speed
- `Spread (deg)` — angular spread around direction
- `Size` — particle size in pixels
- `Lifespan (s)` — particle lifetime in seconds
- `Direction (deg)` — base emission angle (0 = right, -90 = up)

Start / Stop / Clear buttons control playback.
