# UI Examples

Starter examples for migrated UI components.

- `index.html`: landing page linking all examples
- `keyboard.html`: `ui-key` and `ui-key-group`
- `scroll.html`: `scroll-view` and `scroll-bar`
- `gauge.html`: `gauge-bar`
- `shapes.html`: `shape-circle` and `shape-square`
- `sortable-list.html`: `sortable-list`
- `expandable-list.html`: `expandable-list`
- `checklist.html`: `ui-checklist` and `ui-checklist-item`
- `tabs.html`: `ui-tabs` and `ui-content`
- `progress.html`: `ui-progress`
- `register.mjs`: registers components used by examples
